Update

Updating replaces the app and nothing else. Your settings, presets and backups stay where they are.

If you installed with install.sh

Go to the folder you cloned, pull the latest version and run the installer again:

cd plasmify
git pull
./install.sh

The installer removes the old copy in ~/.local/lib/plasmify, copies the new one and rewrites the launcher, menu entry and icon. It never touches what Plasmify stored for you:

WhatWhere
Your own presets (saved, imported or made in the theme studio)~/.config/plasmify/presets
Downloaded wallpapers and the pictures you dropped into Customize~/.local/share/plasmify
Backups, download history, remembered Customize tweaks and the error log~/.local/state/plasmify
Generated colour schemes, icon overlays, panel styles and splash screensunder ~/.local/share

Check which version you have with:

plasmify --version

What changed in each version is listed in the changelog.

Lost the folder you cloned?

Clone the repository again into any folder and run ./install.sh there. It replaces the installed copy in the same way.

Your desktop after an update

Updating the app does not change your desktop: the theme you applied stays exactly as it is. To pick up improvements to a preset, or fixes in how a part is applied, select the preset and press Apply theme again. Your Customize tweaks for that preset are remembered and applied on top, and a new backup is taken first, as always.

If you use the Arch package

After git pull, check that pkgver in packaging/arch/PKGBUILD names the release you want, then build and install again:

cd plasmify/packaging/arch
makepkg -si

pacman replaces the old package. Your data in your home folder is kept, just like with install.sh.

If you run it from the cloned folder

git pull is all you need.
