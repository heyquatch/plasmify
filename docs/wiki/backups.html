Backups and restore

Before every apply, Plasmify saves the settings files it is about to change. Restoring a backup puts your settings back as they were at that moment.

What is backed up

Every apply starts with a backup of every configuration file the selected steps will change. Files that did not exist yet are recorded too, so that restoring removes what Plasmify created. Folders that Plasmify generates, such as the icon overlay or the splash screen, are backed up as a whole. Plasmify's own record of your Customize changes (~/.local/state/plasmify/applied-tweaks.json) is saved with every backup as well.

StepFiles
Colourskdeglobals, kwinrc, plasmarc, the generated ~/.local/share/color-schemes/Plasmify*.colors
Application stylekdeglobals, ~/.config/Kvantum/kvantum.kvconfig and a Kvantum theme folder of the same name; with glass, also its glass theme folder (<theme>-glass or plasmify-glass), and kwinrc when Frosted or Glass turns on blur for a preset without effects
Iconskdeglobals, the overlay theme ~/.local/share/icons/Plasmify-*
Cursorkcminputrc
Fontskdeglobals
Panel layout and Panel styleplasma-org.kde.plasma.desktop-appletsrc, plasmashellrc, plasmarc, the generated panel style
Wallpapersplasma-org.kde.plasma.desktop-appletsrc, kscreenlockerrc
Effectskwinrc, kdeglobals
Terminalkonsolerc, Plasmify's Konsole profile and colours, alacritty.toml, kitty.conf and its theme file
Shell promptstarship.toml, the fastfetch config and logo, config.fish, .bashrc, .zshrc
Splash screenksplashrc, the generated splash package
Login screenThe values of the keys Plasmify changes in the login manager's config (see below)

Downloaded themes, cursors, wallpapers (with their living Shimmer versions) and fonts are not backed up, and packages Plasmify installed stay installed: none of them change your desktop on their own. File > Clean up unused downloads (or plasmify clean) removes the downloads you no longer use.

Where backups are stored

In ~/.local/state/plasmify/backups, one folder per backup, named after the date and time it was made (for example 20261018-214503). That name is the backup's id. Each folder holds the copied files and a small manifest.json that lists them. Backups are labelled after the preset that was about to be applied, such as Before Nord Minimal.

Which backups are kept

  • The first backup is always kept. The very first time you apply anything, the backup is labelled Your setup before Plasmify and marked (always kept). It is never deleted.
  • It keeps growing with you. Whenever a later apply changes a file that the first backup does not hold yet, the original version of that file is added to it. So it holds the original of every file in the table above that Plasmify ever changed, even after hundreds of applies.
  • The 10 newest backups are kept as well. Older ones are deleted automatically.

What restoring does

Restoring a backup puts your settings back as they were at the moment that backup was taken. A backup only holds the files its own apply changed, so Plasmify also puts back every file that later applies changed, each one as it was at that moment. Colours, effects or the prompt from a later apply do not linger.

  • If panels or the wallpaper are involved, Plasma restarts once, so your panels disappear for a moment.
  • The colour scheme, cursor and icons are re-applied, and the window manager reloads its settings.
  • When a Plasmify theme is back on screen, its Customize changes come back as they were at that moment, so the window, plasmify theme and the next change all start from what you see. The changes you made to other presets stay remembered.
  • Terminals that are already open keep their prompt; new terminal windows use the restored one.
  • Restoring does not delete any backups.
Restore is not a redo

Backups hold the setup from before each apply. To get a theme back after restoring, simply apply it again; your Customize tweaks for it are remembered.

Restore in the window

  1. Press Restore… at the bottom of the main window, or use File > Restore a backup….
  2. Pick a backup. Each line shows its date and label; the first one ever is marked (always kept).
  3. Press Restore and confirm. Wait until the log says Restored.; the dialog stays open until the restore has finished.

Restore from the command line

plasmify restore                  # list backups, newest first
plasmify restore latest           # undo the last apply
plasmify restore original         # your setup from before Plasmify
plasmify restore 20261018-214503  # a specific backup, by its id
plasmify restore latest --dry-run # show what would happen, change nothing

After every apply, the command line also prints the exact command to undo it, for example Undo with: plasmify restore 20261018-214503.

The login screen part

The login screen is the only part that lives in a system file, so restoring it asks for your password once. For safety, the backup does not keep a copy of that file. It keeps only the values of the few settings Plasmify writes there, and root writes them back only after they pass strict checks. When no login setting refers to Plasmify's login picture any more, its folder (/usr/share/wallpapers/plasmify-login) is removed.

Backups made by very old versions of Plasmify cannot restore the login screen; in that case reset it in System Settings.
