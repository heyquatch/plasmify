Command line

Presets, light and dark, many settings, backups and sharing also work from a terminal; the theme studio and the panel builder are in the window only. plasmify gui opens the window, and plasmify on its own shows the list of commands.

usage: plasmify [-h] [--version] <command> ...

Global options

-h, --help
Show help. Works after every command too, for example plasmify apply --help.
--version
Show the version, for example plasmify 0.1.0.

Most commands name a preset by its id, the short name that plasmify list shows (such as nord-minimal). plasmify theme is more forgiving and also takes a preset's name or a part of it. Output from servers and files is cleaned of terminal control characters before it is printed.

Quick commands for the applied theme

theme, set and reset work on the applied theme: the Plasmify theme on your desktop right now, the preset marked ● Active in the window. They share what the window knows: changes you make with plasmify set show up on the Customize tab, and changes you made in the window come along when you apply the preset again with plasmify theme.

plasmify theme                    # show the applied theme and its key settings
plasmify theme nord               # apply Nord Minimal (a part of the name is enough)
plasmify theme --toggle           # switch the applied theme between light and dark
plasmify set accent ff79c6 blur on
plasmify reset                    # drop your changes to the applied theme

Before they change the desktop, they print what will run and ask [Y/n]. They share these options:

-y, --yes
Do not ask before changing the desktop. Without a terminal to ask in, nothing changes unless you add --yes. It never approves untrusted servers.
--dry-run
Print what would happen, including every command that would run, without changing anything.
--allow-host HOST
Approve downloads from a server outside the trusted list, like apply. Repeat it once per server.

Every change is backed up first, so plasmify restore latest undoes it like any apply.

theme

plasmify theme [--light | --dark | --toggle] [--only ONLY] [--skip SKIP] [--plain] [-y] [--dry-run] [--allow-host HOST] [name]

Shows the applied theme, applies a preset by a forgiving name, or switches the applied theme between light and dark like the window's button.

  • Without anything, it prints the applied theme, whether it is dark or light (and whether that was switched from the preset's own colours), and its key settings. A * marks the settings you changed from the preset, in the window or with plasmify set. If no Plasmify theme is applied yet, it says so and tells you how to apply one.
  • With a name, it applies that preset. The name can be a preset id, its name, the start of either, one of its words or tags, or a close spelling: nord, nordic and "Nord Minimal" all mean Nord Minimal, and latte means Catppuccin Latte. When it fits several presets, such as rose (Rosé Pine Cozy and Rosé Pine Dawn), they are listed and nothing changes. Changes you made to that preset come along; --plain applies the preset exactly as it is defined.
  • With --light, --dark or --toggle, it turns the applied theme into its light or dark version, or the other mode. The colours and the parts that depend on them change; wallpapers, panel layout, fonts, cursor and effects stay. See Dark and light.
--light, --dark, --toggle
Switch the applied theme to light colours, dark colours, or the other mode. Leave out the name, --only, --skip and --plain.
--only ONLY, --skip SKIP
Comma-separated steps to apply or to skip, with the same ids as apply.
--plain
Leave out the changes you made to this preset.

Examples:

plasmify theme                       # show the applied theme, its mode and key settings
plasmify theme nord                  # apply Nord Minimal ("nordic" or "Nord Minimal" work too)
plasmify theme tokyo --skip layout,effects
plasmify theme dracula --dry-run     # show the commands without running them
plasmify theme --toggle              # switch the applied theme between light and dark
plasmify theme --light               # switch it to light colours (--dark for dark)

set

plasmify set [--list] [-y] [--dry-run] [--allow-host HOST] [KEY VALUE ...]

Changes settings of the applied theme. Give one or more settings, each followed by its new value (up to 32 at once). They are applied at once, after a backup, but only the parts of the desktop they touch run again. They are kept, so the window shows them as Customize changes and plasmify theme brings them along next time. Before it asks, set prints each change as old value -> new value and the steps that will run; it also warns when a new accent is hard to see on the background.

--list
List every setting with the values it takes.
SettingValues
accentA #rrggbb colour, or a palette colour: red, orange, yellow, green, cyan, blue or magenta
glassSee-through app windows, one of four looks: off (solid), frosted (blurred, a little see-through), glass (clearly see-through, light blur) or clear (see-through, no blur). solid, none and no mean off; on and yes mean glass; the older subtle means frosted
transparencyHow see-through glass windows are: 10% to 70% (45, 45% and 0.45 all work). Also called see-through. Each look has its own default, lower on light palettes; see See-through
focused-solidon or off: keep the window you use solid, so only the windows behind it are see-through. Also called solid-focus. On in every look unless you turn it off; see The window you use
shimmerLiving wallpapers: none, sparkle, embers, petals, snow, fireflies, bokeh, starfall, rain, magic, speedlines or calm
shimmer-lightThe light over the picture: auto, glint, rays, flare, pulse or none (auto suits the style)
shimmer-motionHow the picture moves: auto, breathe, drift or still (auto suits the style)
shimmer-densityHow many particles: low, normal or high
shimmer-fpsFrames per second: 12 (lighter) or 24 (smoother)
shimmer-colourA palette colour name (accent, yellow, orange, magenta…) or #rrggbb
shimmer-alwayson or off: keep the shimmer moving while windows cover the desktop
intervalTime between slideshow pictures: 300, 90s, 15m or 1h (1 minute to 24 hours)
bluron or off: blur behind panels and menus
blur-strength1 to 15
wobblyoff, on, or a level from 0 (a little) to 4 (a lot)
cubeon or off: the desktop cube (Meta+C)
fall-aparton or off: closing windows fall apart
sheeton or off: dialogs slide down out of their window's title bar
blur-saturationHow vivid colours behind blur look: 100% (as they are) to 500%
blur-noiseGrain on blurred surfaces, for a frosted look: 0 (none) to 14
moving-opacityHow opaque windows are while you move them: 30% to 100% (or 0.3 to 1.0)
dim-inactiveoff, or how much to dim windows you are not using: 10 to 90
panel-opacity20% to 100% (or 0.2 to 1.0)
radiusPanel corners: 0 to 30 pixels
ui-fontAn installed font, for example "Noto Sans" (quote names with spaces)
mono-fontAn installed monospace font, for example "JetBrains Mono"
font-sizeInterface font size: 6 to 24
mono-sizeMonospace font size: 6 to 32
iconsAn installed icon theme, for example Papirus-Dark
cursorAn installed cursor theme, for example Bibata-Modern-Ice

Every setting also takes default: back to the preset's own value. A # starts a comment in the shell, so quote colours ('#ff79c6') or leave the # out (ff79c6). Fonts, icon themes and cursors must already be installed; a near miss gets a Did you mean suggestion. The Shimmer settings and interval need a theme that sets the wallpaper, and interval needs more than one picture. blur-strength, blur-saturation and blur-noise only take effect while blur is on. transparency and focused-solid need glass: while glass is off, give a look in the same command, such as plasmify set glass frosted transparency 30%. plasmify set transparency default goes back to the preset's own amount, which for the built-in presets is the look's default.

Examples:

plasmify set accent ff79c6                  # a new accent colour
plasmify set accent magenta                 # or one from the palette
plasmify set glass frosted blur-strength 12
plasmify set glass clear transparency 50%   # see-through windows without blur
plasmify set transparency 45%               # more or less see-through glass
plasmify set glass clear focused-solid off  # see through the window you use too
plasmify set wobbly 3 cube on
plasmify set panel-opacity 80% radius 14
plasmify set ui-font "Noto Sans" font-size 11
plasmify set shimmer petals shimmer-colour accent
plasmify set shimmer magic shimmer-light flare shimmer-motion drift
plasmify set interval 15m
plasmify set radius default                 # back to the preset's own value
plasmify set --list                         # every setting and its values

reset

plasmify reset [-y] [--dry-run] [--allow-host HOST]

Drops the changes made to the applied theme (in the window or with plasmify set) and applies it as the preset defines it. Only the parts of the desktop your changes touched run again, after a backup. If you changed something the preset itself leaves alone, that change stays on the desktop, and reset says so; plasmify restore can undo it. plasmify restore puts back all the settings of an earlier backup instead.

plasmify reset              # drop your changes and apply the preset as it is defined
plasmify reset --dry-run    # show what would run without changing anything

gui

plasmify gui

Opens the window, like the application menu entry does. Without a command, plasmify shows the list of commands instead.

list

plasmify list

Lists all presets, built-in and your own, with their id, name and description. The active preset is marked with *.

show

plasmify show <preset>

Shows what a preset changes and installs: its steps, the packages it needs, the servers it downloads from (and which of them are not on the trusted list), the install summary and the wallpaper credits. Changes nothing.

apply

plasmify apply [--only ONLY] [--skip SKIP] [-y] [--dry-run] [--allow-host HOST] <preset>

Applies a preset: backs up, installs missing packages, downloads and runs every step, printing each one. At the end it prints the command that undoes it, such as Undo with: plasmify restore 20261018-214503.

--only ONLY
Comma-separated steps to apply, and nothing else.
--skip SKIP
Comma-separated steps to skip.
-y, --yes
Do not ask before installing packages. It never approves untrusted servers.
--dry-run
Print what would happen, including every command that would run, without changing anything.
--allow-host HOST
Approve downloads from a server outside the trusted list. Repeat it once per server. Without it, Plasmify asks interactively, and refuses when it cannot ask (with --yes or without a terminal). A preset whose greeting shows the weather counts wttr.in as such a server, because every new terminal would contact it.

Step ids for --only and --skip:

IdStep
colorsColours
styleApplication style
iconsIcons
cursorCursor
fontsFonts
layoutPanel layout
panelstylePanel style
wallpaperWallpapers
effectsEffects
terminalTerminal
shellShell prompt
splashSplash screen
loginLogin screen

Examples:

plasmify apply nord-minimal                          # everything
plasmify apply rose-pine-cozy --skip layout,effects  # keep your panels and effects
plasmify apply tokyo-night-neon --only terminal,shell
plasmify apply gruvbox-retro --dry-run               # show the commands only
plasmify apply friends-preset --allow-host example.org

apply takes the preset exactly as it is defined, by its exact id, without the changes you made in the window or with plasmify set; afterwards the window shows no changes for it. To apply a preset together with your changes, use plasmify theme <name>.

restore

plasmify restore [--dry-run] [backup]

Without an argument, lists your backups, newest first, with their id, date and label; the oldest one, your setup before Plasmify, is marked (always kept). With an argument, restores one:

latest
The newest backup: undoes the last apply.
original
The always-kept Your setup before Plasmify backup. If an older version already removed it, the oldest backup left is used instead, and the command says so.
<id>
A specific backup, for example 20261018-214503.
--dry-run
Show what would happen without changing anything.

Restoring puts your settings back as they were at that moment, including files changed by later applies; packages and downloads stay. See Backups and restore.

clean

plasmify clean [--dry-run]

Deletes the downloaded assets (wallpapers, themes, cursors and generated files) of presets that are not active, and prints how much space was freed. Files every preset shares, such as fonts or the Konsole profile, and themes you are currently using are kept. --dry-run lists what would be removed.

validate

plasmify validate [files ...]

Checks preset files for errors and prints ok or FAIL with the reason for each one. Without files, it checks all built-in presets. Exits with an error if any file fails, which makes it handy in scripts.

plasmify validate my-preset.toml

import

plasmify import [--replace] <file>

Imports a .plasmify bundle (also when renamed to .zip, as presets shared in Discussions are) or a .toml preset into your presets and tells you how to apply it. It also notes when the preset downloads from servers outside the trusted list.

--replace
Overwrite a preset of yours with the same id. Without it, the import stops if one exists.

export

plasmify export [-o OUTPUT] <preset>

Writes a preset to a shareable .plasmify file. Your own pictures go inside; other artists' wallpapers stay linked to their source.

-o, --output OUTPUT
The file to write. Default: <id>.plasmify in the current folder.

save-desktop

plasmify save-desktop [-d DESCRIPTION] [--no-wallpapers] [--replace] <name>

Saves your current desktop, including your exact panels, as a preset of your own, and lists anything it had to leave out.

-d, --description DESCRIPTION
A short description.
--no-wallpapers
Do not include your wallpaper files.
--replace
Overwrite a preset of yours with the same id.
plasmify save-desktop "My Desktop" -d "Calm blues with a side dock"
plasmify export my-desktop

log

plasmify log [-n LIMIT] [--clear]

Shows what Plasmify downloaded or installed, newest first: when, whether it worked, what kind (download, git, packages or fonts), for which preset, from where, where it was saved (for git, the path in the repository), its size and its SHA-256 or git commit. The history stays on your computer, in ~/.local/state/plasmify/activity.jsonl.

-n, --limit LIMIT
Number of entries to show (default 50).
--clear
Delete the history.

steps

plasmify steps

Lists the steps a preset is made of, with their ids and a short description of each.
