Uninstall

There are three levels, from gentle to thorough. Do them in this order. Most people only need the first two.

On this page
  • 1. Put your desktop back
  • 2. Remove the app
  • 3. Remove Plasmify's data (purge)
  • What stays after a purge
  • Arch package users
Start with step 1

Removing the app does not change your desktop. Your colours, panels, wallpaper and prompt stay as they are. Put your old setup back first, while Plasmify is still installed.

1. Put your desktop back

plasmify restore original
  • This restores the backup called Your setup before Plasmify. It is made automatically the first time you apply anything, it is marked (always kept) and it is never deleted by the ten-backup limit.
  • It puts your settings back as they were before your first apply. Every file that later applies changed is put back too, or removed if Plasmify created it: colours, panels, wallpapers, effects, terminal, prompt and splash screen.
  • When panels or the wallpaper come back, Plasma restarts once during the restore, so your panels disappear for a moment.
  • If you changed the login screen background, the restore asks for your password once to put the old login setting back.
  • Used Plasmify before this backup existed? Older versions kept only the ten newest backups. If your setup from before Plasmify is still among them, it becomes Your setup before Plasmify at your next apply. If it was already removed, the oldest one left is called Oldest backup, from an earlier Plasmify version, restore original says so, and you pick your own colours, icons and wallpaper again in System Settings.

In the window: File > Restore a backup… (or the Restore… button), select the line marked (always kept) and press Restore.

Terminals that are already open keep the Plasmify prompt; new terminal windows use your original one. More about backups: Backups and restore.

2. Remove the app

From the folder you cloned:

cd plasmify
./install.sh --uninstall

This removes the app only: ~/.local/lib/plasmify, ~/.local/bin/plasmify, the menu entry and the icon. Your themes, presets, wallpapers and backups stay. If you install Plasmify again later, everything is still there. (If you installed with a custom PREFIX, set the same one here.)

3. Remove Plasmify's data (purge)

./install.sh --purge

This removes the app, exactly like step 2, and also deletes:

PathWhat is in it
~/.local/share/plasmifyDownloaded wallpapers, the pictures you dropped into Customize, preset logos
~/.local/state/plasmifyAll backups (including Your setup before Plasmify), download history, error log, remembered tweaks
~/.config/plasmifyYour own presets
~/.local/share/color-schemes/Plasmify*.colorsGenerated colour schemes
~/.local/share/icons/Plasmify-*Icon overlays (the folder colours)
~/.local/share/plasma/desktoptheme/plasmify-*Generated panel styles (corners, opacity, border, colour)
~/.local/share/plasma/look-and-feel/plasmify-splash-*Generated splash screens

The purge also empties ~/.cache/plasmify (splash previews, which can hold copies of your own splash pictures). If you set XDG_DATA_HOME, XDG_STATE_HOME, XDG_CONFIG_HOME or XDG_CACHE_HOME, the purge follows them.

It is careful about it:

  • It refuses while your desktop still uses anything of Plasmify (its colour scheme, icon theme, panel style, splash screen, wallpapers or terminal logo), says which, and tells you to run plasmify restore original first, then --purge again. If you already removed the app, it gives you the same command to run straight from the downloaded folder.
  • It lists every path it is about to delete and asks you to type yes. Anything else cancels, and nothing is deleted.
  • For scripts, ./install.sh --purge --yes skips the question.
The login screen is not touched

The purge never asks for root, so it does not change the login screen. If you set a login background, restore first (step 1 asks for your password once and puts the old setting back), or reset the login screen in System Settings.

What stays after a purge

Some things may be used by other apps too, so Plasmify leaves them alone. Remove them yourself if you no longer want them:

  • Packages from your distribution that Plasmify installed (fonts, Papirus, Kvantum, Starship, fastfetch, zoxide, chafa and so on). File > Download history… or plasmify log -n 500 lists them. Look before you purge, because the purge deletes that history. Remove them with your package manager.
  • Themes and cursors downloaded for presets, including the Kvantum themes and glass themes in ~/.config/Kvantum (Plasmify's own carry a made-by-plasmify.txt file). After step 1, run plasmify clean (or File > Clean up unused downloads) while the app is still installed. It deletes the downloads of presets that are not active.
  • Fonts your distribution does not package, downloaded into ~/.local/share/fonts/plasmify.
  • The Polonium tiling script, if tiling was switched on:kpackagetool6 --type KWin/Script --remove polonium

The complete order, for a spotless system:

plasmify restore original
plasmify log -n 500     # note the packages you may want to remove later
plasmify clean
./install.sh --purge

Arch package users

If you installed the package built from packaging/arch, remove it with pacman instead of install.sh. Do step 1 first, while the app is still installed:

plasmify restore original
sudo pacman -R plasmify

pacman removes the files under /usr; your data in your home folder stays. To delete that as well, run ./install.sh --purge from a clone of the repository. It only deletes files in your home folder; the part that removes the install.sh copy simply finds nothing to remove.
