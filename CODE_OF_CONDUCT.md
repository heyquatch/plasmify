# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep discussions about
the work rather than the person. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers through
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Maintainers will review every report and respond in a way they deem appropriate,
which can include a warning or a ban from the project.
